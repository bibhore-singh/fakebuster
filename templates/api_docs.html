Developer API Guide

Simple API Guide & Code Examples

“Bust the Fake. Find the Facts.” — Connect FAKEBUSTER's AI fact-checker and source trust engine into your own apps, social bots, or browser extensions.

POST /api/predict

Classifies news text as Reliable or Unreliable and calculates dynamic source visibility reach weight.

Request Payload (JSON)

{
  "title": "NASA James Webb Space Telescope Reveals Ancient Galaxies",
  "author": "Astrophysical Journal (Dr. Sarah Jenkins)",
  "text": "Astronomers have verified unprecedented clusters of early galaxies using infrared spectroscopy..."
}

Response Payload (JSON)

{
  "status": "success",
  "prediction": "Reliable (Authentic News)",
  "is_fake": false,
  "confidence": 96.2,
  "visibility_weight": 0.98,
  "author": "Astrophysical Journal (Dr. Sarah Jenkins)"
}

cURL Example

curl -X POST http://localhost:5000/api/predict \
  -H "Content-Type: application/json" \
  -d '{"title":"Breaking News...", "author":"Reuters", "text":"Article content here..."}'

Python Example

import requests

payload = {
    "title": "NASA Telescope Confirms Early Galaxies",
    "author": "Dr. Sarah Jenkins",
    "text": "Astronomers published peer-reviewed findings..."
}
response = requests.post("http://localhost:5000/api/predict", json=payload)
print(response.json())
GET /api/source/{source_name}

Queries the source credibility registry to retrieve historical trust score and algorithmic feed action.

Response Example

{
  "found": true,
  "source": "reuters",
  "status": "Safe (1.0x)",
  "tier": "Tier 1 (High Credibility)",
  "trust_score": 0.98
}
